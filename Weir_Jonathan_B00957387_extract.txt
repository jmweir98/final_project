The development process is structured into a series of iterations, each focusing on a subset of 
system functionality. Early iterations prioritise core technical components, including route 
generation, elevation analysis, and accessibility scoring, ensuring that high-risk elements are 
addressed at an early stage. Later iterations focus on enhancing usability, integrating user-
generated feedback, and refining system behaviour. Each iteration follows a consistent cycle of 
planning, design, implementation, testing and evaluation, and review and refinement. 
The project is planned across four iterations. Iteration 1 focuses on core routing infrastructure, 
integrating OpenRouteService, retrieving elevation data from Open-Meteo, and implementing the 
rule-based accessibility scoring model. Iteration 2 develops the frontend map interface, route 
comparison view, and score explanation panel. Iteration 3 implements the venue information 
component, user review submission, optional image upload, and authentication. Iteration 4 focuses 
on system-wide testing, usability evaluation, performance assessment, and refinement based on 
evaluation outcomes. Each iteration produces a working increment of the system, with 
requirements reviewed and reprioritised at the start of each cycle in response to findings from the 
previous iteration. The iteration cycle applied throughout development is illustrated in Figure 4.1.

4.2. Initial plans 
The research and requirements phase has involved literature review, analysis of existing systems, 
and definition of system requirements, and is formalised through the submission of this report. 
The design phase will follow, where system architecture, data models, and user interface concepts 
will be developed. This phase must precede implementation to ensure technical decisions are 
grounded in a validated understanding of system requirements and constraints. 
The implementation phase will focus on core functionality, including integration with routing and 
elevation APIs, development of the accessibility scoring model, and validation of route processing.
